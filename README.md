# HR-Employee-Attrition-Analysis-Excel
HR Employee Attrition Analysis Dashboard built using Microsoft Excel to analyze employee demographics, attrition trends, job satisfaction, salary bands, departments, and job roles.

## 📌 Project Overview

This project analyzes employee data to understand employee attrition and identify the key factors associated with employees leaving an organization.

An interactive HR dashboard was created using Microsoft Excel to provide insights into employee demographics, attrition, departments, job roles, salary, age groups, and other employee-related factors.

## 🛠️ Tools Used

- Microsoft Excel
- Data Cleaning
- Excel Formulas
- Pivot Tables
- Pivot Charts
- Data Visualization
- Dashboard Development
- ## 📊 Key KPIs

- Total Employees
- Total Attrition
- Attrition Rate
- Average Employee Age
- Department-wise Attrition
- Job Role-wise Attrition
- Age Group Analysis
- Salary Analysis
- Marital Status Analysis

## 🔍 Analysis Performed
The project analyzes employee attrition based on:

- Department
- Job Role
- Age Group
- Gender
- Marital Status
- Salary
- Job Satisfaction
- Employee Demographics

## 🎯 Project Objective

The main objective of this project is to analyze employee attrition patterns and identify important HR insights that can help organizations understand employee turnover and improve retention strategies.
